# 🔖 Save My Links Board

**Save, organize, search, and manage your favorite web links in one simple place.**

Save My Links Board is a lightweight, browser-based bookmark management application built using HTML, CSS, and JavaScript. It helps users keep useful websites, study resources, and favorite URLs organized without needing an account or a backend server.

The application stores links locally in the browser and provides options to search, categorize, favorite, delete, import, and export bookmarks.

## 📸 Project Preview



## ✨ Features

- **Save Links:** Add website URLs with an optional custom title.
- **Organize by Category:** Assign categories to bookmarks, such as Study.
- **Search Bookmarks:** Quickly find saved links by title or URL.
- **Favorite Links:** Mark important bookmarks using the star button.
- **Delete Links:** Remove individual bookmarks when they are no longer needed.
- **Import and Export JSON:** Back up bookmarks and transfer them between browsers or devices.
- **Clear All:** Remove all saved links when required.
- **Local Storage:** Keep saved bookmarks in the browser without requiring a server or database.
- **Simple Interface:** Use a straightforward dashboard to manage saved resources.

## 🚀 Getting Started

You can run this project locally without installing any additional packages.

### Prerequisites

- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- A code editor such as Visual Studio Code (optional).

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd Web-Design-Project
```

**3. Open the project**

Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code for local development.

That's it! You can start saving and organizing your links.

## 📖 How to Use

1. **Add a bookmark:** Enter a website URL in the URL field.
2. **Add a title:** Optionally provide a meaningful title for the link.
3. **Choose a category:** Select an available category from the dropdown.
4. **Save the link:** Click the Save button to add it to your collection.
5. **Search links:** Enter a title or URL in the search field to find a bookmark.
6. **Manage favorites:** Click the star button to mark or unmark a link as a favorite.
7. **Delete bookmarks:** Use the delete button to remove an individual link.
8. **Export bookmarks:** Download your saved links as a JSON file for backup.
9. **Import bookmarks:** Paste previously exported JSON data to restore or transfer links.
10. **Clear all bookmarks:** Use Clear All when you want to remove your saved collection.

## 💾 Data Storage

Save My Links Board uses browser-local storage to retain bookmarks between visits.

- No user registration or login is required.
- Bookmarks are stored locally in the browser.
- Data is not automatically synchronized between devices or browsers.
- Export your bookmarks regularly to keep a portable backup.
- Clearing browser site data may remove stored bookmarks.

**Note:** Import and export functionality is useful for transferring bookmarks, but the application does not provide cloud synchronization.
